# Guru — Release Checklist

## Requirements and product
- [ ] Approved scope and version baseline recorded.
- [ ] FRD and RTM updated.
- [ ] Acceptance criteria reviewed by product owner.

## Documents and knowledge base
- [ ] Each PDF is from an identifiable official source.
- [ ] Issuing authority, state, category, scheme year and source URL recorded.
- [ ] Documents checked for duplicates and superseded versions.
- [ ] Scanned documents identified; OCR need documented.

## RAG quality
- [ ] Gold evaluation questions prepared and reviewed.
- [ ] Retrieval relevance measured.
- [ ] Citations verified against exact pages.
- [ ] Out-of-corpus questions tested for abstention.
- [ ] Multi-turn follow-up questions tested.
- [ ] All supported languages reviewed by fluent speakers for representative cases.

## Security and privacy
- [ ] Secrets are not committed.
- [ ] Authentication/authorization appropriate to deployment is enabled.
- [ ] Upload size/type/content controls reviewed.
- [ ] Prompt-injection and malicious-document tests completed.
- [ ] Data retention and deletion policy documented.
- [ ] HTTPS and deployment secrets configured for hosted deployments.

## Operations
- [ ] Dependency versions and Python version pinned.
- [ ] Automated tests pass.
- [ ] Backups and restore procedure tested.
- [ ] Logs and failure monitoring configured.
- [ ] Cost/usage limits reviewed.
- [ ] User-facing disclaimer and support contact reviewed.
